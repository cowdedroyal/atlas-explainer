Media: a pipeline in motion and its data

This card is the kit's example for baked media. It follows the same row as the other example, but shows it moving, and then plots the run it belongs to. All numbers are made up, so every picture carries the “illustrative” badge.

A still cannot show the order of events: which box a row enters, where another one disappears. The animation below is a baked frame sequence — no script of the card's own, no network — so it plays here and keeps working when the card is opened from git on a laptop with no server.

Scrub the slider to stop on a stage. The frames were drawn by media/src/flow/gen.py; a real card would render a Motion Canvas scene (or a Manim clip) to the same kind of stills.

The animation follows one row, which hides the scale. The same run, counted at each stage:

Two thirds of the input is gone after filter, and none of the rest is lost afterwards. That asymmetry is the reason the card exists: the expensive part of the pipeline is not the cleaning, it is what the filter throws away.

This chart is interactive: hover a bar for the count, and click a legend entry to isolate that category. It is a Vega-Lite spec compiled at bake time, drawn by the Vega runtime inlined into the card.

The long tail is exactly what normalization is for: running shoes, Running Shoes and running shoe are three bars until canon_label folds them into one.
