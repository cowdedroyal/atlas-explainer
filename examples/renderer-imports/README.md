# Real renderer exports

The inputs here were exported by Motion Canvas 3.17.2 and Manim Community 0.22.0, rather than generated by the
card kit. They exercise the two supported import paths without requiring either renderer on a reader's machine.
All example scene source and outputs are distributed under this repository's Apache-2.0 license.
Motion Canvas and Manim themselves are MIT licensed and are authoring tools, not runtime dependencies.

- `media/src/motion/scene.tsx` is a Motion Canvas 2D scene. Render at 320×180 and 12 FPS to PNG image sequence;
  the checked-in 13 frames include the endpoint at one second. In a standard Motion Canvas project, import this
  scene with `?scene` in `makeProject({scenes: [...]})` and export the image sequence.
- `media/src/manim/scene.py` was rendered using `manim -ql --disable_caching scene.py Flow`.
  `Flow.mp4` contains 15 frames at 15 FPS, lasting exactly one second.

Run `atlas-explainer bake examples/renderer-imports`, then lint and pack. The Manim output is sampled to 10 FPS
while preserving its one-second duration. The exported Motion Canvas stills use their authored 12 FPS.
